Sales Data Analytics Project

Project Overview
This project analyzes retail sales data to uncover trends, top-performing products, and regional performance.

 Tools Used
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- Power BI

 Key Analysis
- Cleaned raw sales data (duplicates, missing values, formatting issues)
- Calculated revenue per transaction
- Analyzed revenue by product, region, and month

 Visualization
An interactive Power BI dashboard was created to explore:
- Revenue by Product
- Monthly Sales Trends
- Regional Performance

 Project Structure
See repository folders for data, notebooks, and visuals.

 Outcome
This project demonstrates an end-to-end data analytics workflow:
data cleaning → analysis → visualization → insights.
